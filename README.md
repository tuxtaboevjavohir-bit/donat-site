# Донат-алерт

Сайт для TikTok-стримеров: зритель переводит донат на Kaspi и оставляет заявку, стример подтверждает, уведомление появляется в эфире.

## Запуск
    node server.js        # нужен Node.js 18+, зависимостей нет
    открыть http://localhost:3000

## Как пользоваться
1. На главной странице создайте аккаунт (ник, пароль, номер Kaspi).
2. Ссылку `/s/ваш_ник` дайте зрителям.
3. Ссылку оверлея `/overlay/ваш_ник?key=...` добавьте в TikTok LIVE Studio (источник «Link») или в OBS (Browser Source).
4. Заявки зрителей появляются в панели; сверьте с Kaspi и нажмите «Подтвердить».

## Выкладка в интернет
Подойдёт любой хостинг с Node.js (Render, Railway, Fly.io, VPS). Команда запуска: `node server.js`.
Данные хранятся в `data.json`; на хостинге подключите постоянный диск и укажите путь в переменной `DATA_FILE`.
Нужен HTTPS (его даёт сам хостинг), иначе TikTok и браузеры могут блокировать оверлей.
